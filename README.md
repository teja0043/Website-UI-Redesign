# Website UI Redesign

## Project Overview
Redesigned an existing website to improve usability, visual hierarchy, and responsive design.

## Selected Website
Netflix Landing Page

## Objectives
- Improve user experience
- Enhance visual hierarchy
- Create responsive layouts
- Apply modern UI design principles

## Design Process

### 1. Heuristic Evaluation
Identified usability issues in the existing design.

### 2. Mood Board
Created a modern visual direction using premium streaming platform inspirations.

### 3. Style Guide
Defined typography, colors, spacing, and component styles.

### 4. High-Fidelity Mockups
Designed responsive desktop and mobile interfaces.
